## 框架简介

### 什么是 go-Dai

go-Dai 是一款集多协议、多数据库引擎于一体的 Go 服务开发框架，特别沿用 PHP 主流框架设计思路，更适配 PHP 程序员的开发习惯，降低 Go 语言技术栈的学习与迁移成本。

### 核心特性

- **PHP友好，低迁移成本**：沿用 Laravel/ThinkPHP 等主流 PHP 框架的 MVC 分层思想、路由设计规范及控制器写法
- **多协议统一**：一套编码规范即可开发 HTTP、WebSocket、gRPC 多种服务接口
- **数据库操作便捷**：兼容 MySQL、MongoDB、Redis、ElasticSearch 等主流数据库引擎，支持简洁高效的链式调用
- **开箱即用**：内置完善的默认配置、统一错误处理、常用中间件基础能力
- **服务切换成本低**：基于 MVC 全链路高一致性设计，模型与服务层完全脱离协议依赖

### 适用场景

- PHP 程序员转 Go 开发
- 需要快速落地多协议服务的团队
- 需要统一开发规范的微服务架构
- 需要高性能且保持开发效率的项目

## 核心架构

### MVC 分层设计

框架采用严格的 MVC 分层设计，各层职责清晰：

```
┌─────────────────────────────────────────┐
│           Controller (控制器层)           │
│  - 请求分发、参数校验、响应封装             │
│  - 仅调用服务层，不直接操作数据             │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│            Service (服务层)               │
│  - 封装核心业务逻辑                        │
│  - 多协议复用的核心                        │
│  - 仅通过模型层操作数据                    │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│             Model (模型层)                │
│  - 映射数据实体                           │
│  - 负责 CRUD 操作                         │
│  - 仅被服务层调用                          │
└─────────────────────────────────────────┘
```

### 多协议统一架构

框架通过统一的上下文接口（netContext.Context）实现多协议统一：

```
┌─────────────────────────────────────────┐
│         netContext.Context 接口          │
│  - GetRequestInfo()                      │
│  - JSON/String/Query/PostForm            │
│  - BindJSON/SetParam/GetParam            │
└─────────────────────────────────────────┘
          ↑           ↑           ↑
          │           │           │
    ┌─────┴───┐  ┌────┴────┐  ┌───┴─────┐
    │ HTTP    │  │WebSocket│  │  gRPC   │
    │ Context │  │ Context │  │ Context │
    └─────────┘  └─────────┘  └─────────┘
```

### 核心模块组成

框架由以下核心模块组成：

1. **Bootstrap（启动模块）**：统一服务启动入口，支持多协议服务同时启动
2. **Config（配置模块）**：支持 JSON 格式配置文件，支持多环境配置切换
3. **Base（基础模块）**：提供 BaseController、BaseService、BaseModel 等基类
4. **HTTP（HTTP 服务模块）**：HTTP 服务器、路由、中间件
5. **WebSocket（WebSocket 服务模块）**：WebSocket 服务器、连接管理、事件监听
6. **gRPC（gRPC 服务模块）**：gRPC 服务器、路由、拦截器
7. **Database（数据库模块）**：MySQL、MongoDB、Redis、ElasticSearch 支持
8. **Logger（日志模块）**：统一日志管理
9. **Function（功能函数模块）**：常用工具函数

#### 3. 创建模型层

创建 `app/api/model/user/user.go`：

```go
package user

import (
    "context"
    "encoding/json"
    "errors"
    "time"
    "github.com/dfpopp/go-dai/base"
)

// User 用户数据模型
type User struct {
    ID       int    `json:"id"`
    Username string `json:"username"`
    Email    string `json:"email"`
    Age      int    `json:"age"`
}

// Model 用户模型
type Model struct {
    *base.BaseModel
    DbTag string
    Table string
}

// NewModel 创建用户模型实例
func NewModel() *Model {
    return &Model{
        BaseModel: &base.BaseModel{},
        DbTag:     "default",
        Table:     "users",
    }
}

// GetOne 查询单个用户
func (m *Model) GetOne(field string, whereTpl string, whereValues []interface{}) (*User, error) {
    m.Init()
    db, err := m.GetMysqlDb(m.DbTag)
    if err != nil {
        return nil, err
    }
    
    db.SetTable(m.Table)
    if field != "" {
        db.SetField(field)
    }
    if whereTpl != "" {
        db.SetWhere(whereTpl, whereValues...)
    }
    
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
    defer cancel()
    
    retStr, err := db.Find(ctx)
    if err != nil {
        m.LogError(err)
        return nil, errors.New("数据查询失败")
    }
    
    if retStr == "" {
        return nil, nil
    }
    
    var user User
    err = json.Unmarshal([]byte(retStr), &user)
    if err != nil {
        return nil, err
    }
    
    return &user, nil
}

// GetList 查询用户列表
func (m *Model) GetList(field string, whereTpl string, whereValues []interface{}, page int64, pageSize int64) ([]User, error) {
    m.Init()
    db, err := m.GetMysqlDb(m.DbTag)
    if err != nil {
        return nil, err
    }
    
    db.SetTable(m.Table)
    if field != "" {
        db.SetField(field)
    }
    if whereTpl != "" {
        db.SetWhere(whereTpl, whereValues...)
    }
    if page > 0 && pageSize > 0 {
        db.SetLimit((page-1)*pageSize, pageSize)
    }
    
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
    defer cancel()
    
    retStr, err := db.FindAll(ctx).ToString()
    if err != nil {
        return nil, err
    }
    
    if retStr == "" {
        return nil, nil
    }
    
    var users []User
    err = json.Unmarshal([]byte(retStr), &users)
    return users, err
}
```

```go
package user

import (
    "errors"
    "myproject/app/api/model/user"
    "github.com/dfpopp/go-dai/base"
)

// Service 用户业务服务
type Service struct {
    *base.BaseService
    userModel *user.Model
}

// NewService 初始化用户服务
func NewService() *Service {
    return &Service{
        BaseService: &base.BaseService{},
        userModel:   user.NewModel(),
    }
}

// GetUserById 根据ID查询用户信息
func (s *Service) GetUserById(userId int) (*user.User, error) {
    s.Init()
    
    if userId <= 0 {
        return nil, errors.New("用户ID非法")
    }
    
    field := "id,username,email,age"
    userInfo, err := s.userModel.GetOne(field, "id=?", []interface{}{userId})
    if err != nil {
        s.LogError(err)
        return nil, errors.New("用户查询失败")
    }
    
    return userInfo, nil
}

// GetUserList 查询用户列表
func (s *Service) GetUserList(page int64, pageSize int64) ([]user.User, error) {
    s.Init()
    
    if page < 1 {
        page = 1
    }
    if pageSize > 100 {
        pageSize = 100
    }
    
    field := "id,username,email,age"
    users, err := s.userModel.GetList(field, "", nil, page, pageSize)
    if err != nil {
        s.LogError(err)
        return nil, errors.New("用户列表查询失败")
    }
    
    return users, nil
}
```

#### 5. 创建控制器层

创建 `app/api/controller/user/user.go`：

```go
package user

import (
    "strconv"
    "myproject/app/api/service/user"
    "github.com/dfpopp/go-dai/base"
    "github.com/dfpopp/go-dai/netContext"
)

// Controller 用户控制器
type Controller struct {
    *base.BaseController
    userService *user.Service
}

// NewController 创建控制器实例
func NewController() *Controller {
    return &Controller{
        BaseController: &base.BaseController{},
        userService:    user.NewService(),
    }
}

// GetUser 获取用户信息
func (c *Controller) GetUser(ctx netContext.Context) {
    c.Init(ctx)
    
    userIdStr := c.GetPostForm("id")
    if userIdStr == "" {
        c.Error(400, "用户ID不能为空")
        return
    }
    
    userId, err := strconv.Atoi(userIdStr)
    if err != nil {
        c.Error(400, "用户ID格式错误")
        return
    }
    
    userInfo, err := c.userService.GetUserById(userId)
    if err != nil {
        c.Error(500, err.Error())
        return
    }
    
    if userInfo == nil {
        c.Error(404, "用户不存在")
        return
    }
    
    c.Success(userInfo)
}

// GetUserList 获取用户列表
func (c *Controller) GetUserList(ctx netContext.Context) {
    c.Init(ctx)
    
    pageStr := c.GetPostForm("page")
    pageSizeStr := c.GetPostForm("pageSize")
    
    page := int64(1)
    pageSize := int64(10)
    
    if pageStr != "" {
        page, _ = strconv.ParseInt(pageStr, 10, 64)
    }
    if pageSizeStr != "" {
        pageSize, _ = strconv.ParseInt(pageSizeStr, 10, 64)
    }
    
    users, err := c.userService.GetUserList(page, pageSize)
    if err != nil {
        c.Error(500, err.Error())
        return
    }
    
    c.Success(users)
}
```

## 核心模块详解

### Bootstrap 启动模块

Bootstrap 模块提供统一的服务启动入口，支持多协议服务同时启动。

#### BootConfig 配置结构

```go
type BootConfig struct {
    AppName            string          // 应用名（如 api/admin）
    AppConfigPath      string          // 应用配置文件路径
    DatabaseConfigPath string          // 数据库配置文件路径
    CustomConfigPath   string          // 自定义配置文件路径（可选）
    EnableServices     []ServiceType   // 需要启动的服务类型
    Router             base.BaseRouter // 应用路由实例
    ShutdownFunc       func()          // 服务关闭时的回调函数（可选）
}
```

#### ServiceType 服务类型

```go
const (
    ServiceTypeHTTP ServiceType = "http"
    ServiceTypeWS   ServiceType = "ws"
    ServiceTypeGRPC ServiceType = "grpc"
)
```

#### 启动示例

```go
// 单服务启动
bootCfg := &bootstrap.BootConfig{
    AppName:            "api",
    AppConfigPath:      "config/app.json",
    DatabaseConfigPath: "config/database.json",
    EnableServices:     []bootstrap.ServiceType{bootstrap.ServiceTypeHTTP},
    Router:             router.NewApiRouter(),
}

// 多服务同时启动
bootCfg := &bootstrap.BootConfig{
    AppName:            "api",
    AppConfigPath:      "config/app.json",
    DatabaseConfigPath: "config/database.json",
    EnableServices:     []bootstrap.ServiceType{
        bootstrap.ServiceTypeHTTP,
        bootstrap.ServiceTypeWS,
        bootstrap.ServiceTypeGRPC,
    },
    Router: router.NewApiRouter(),
}
```

**中间件示例**：

```go
// 认证中间件
func Auth() MiddlewareFunc {
    return func(next HandlerFunc) HandlerFunc {
        return func(c *Context) {
            token := c.GetHeader("Authorization")
            if token == "" {
                c.JSON(200, map[string]interface{}{
                    "code": 401,
                    "msg":  "未授权访问",
                })
                return
            }
            next(c)
        }
    }
}

// 日志中间件
func Logger() MiddlewareFunc {
    return func(next HandlerFunc) HandlerFunc {
        return func(c *Context) {
            startTime := time.Now()
            next(c)
            endTime := time.Now()
            fmt.Printf("请求路径：%s，耗时：%v\n", 
                c.Req.URL.Path, 
                endTime.Sub(startTime))
        }
    }
}
```

**实现连接事件处理器**：

创建 `app/api/init/ws/listener.go`：

```go
package ws

import (
    "encoding/json"
    "github.com/dfpopp/go-dai/logger"
    "github.com/dfpopp/go-dai/websocket"
    "github.com/google/uuid"
)

// CustomConnListener 应用层自定义监听器（实现ConnectionEventHandler接口）
type CustomConnListener struct {
    // 可注入应用层业务服务（如好友服务、消息服务）
}

// NewCustomConnListener 创建监听器实例
func NewCustomConnListener() *CustomConnListener {
    return &CustomConnListener{}
}

// OnConnect 处理用户上线逻辑（应用层自定义）
func (l *CustomConnListener) OnConnect(connInfo *websocket.ConnInfo) {
    connID := connInfo.ConnID
    clientIP := connInfo.ClientIP

    // 示例1：打印上线日志
    logger.Info("用户上线", "connID", connID, "clientIP", clientIP, "onlineTime", connInfo.CreateTime)

    // 示例2：获取连接绑定的用户ID（若应用层已设置）
    userIDVal, exists := websocket.GetGlobalConnManager().GetConnAttr(connID, "user_id")
    if exists {
        userID, _ := userIDVal.(string)
        logger.Info("用户绑定成功", "userID", userID, "connID", connID)

        // 示例3：通知该用户的好友（应用层需自行实现好友关系查询）
        // friends := friendService.GetFriendList(userID)
        // 组装上线通知
        notifyMsg := map[string]interface{}{
            "action":     "friend.online",
            "request_id": uuid.NewString(),
            "data": map[string]interface{}{
                "user_id":   userID,
                "conn_id":   connID,
                "online_at": connInfo.CreateTime.Format("2006-01-02 15:04:05"),
            },
        }
        msgBytes, _ := json.Marshal(notifyMsg)
        // 给好友群发通知（需传入好友的ConnID列表）
        websocket.GetGlobalConnManager().Multicast([]string{"好友connID"}, string(msgBytes))
    }
}

// OnDisconnect 处理用户下线逻辑（应用层自定义）
func (l *CustomConnListener) OnDisconnect(connInfo *websocket.ConnInfo, reason string) {
    connID := connInfo.ConnID
    clientIP := connInfo.ClientIP
    closeReason := reason

    // 示例1：打印下线日志
    logger.Info("用户下线", "connID", connID, "clientIP", clientIP, "offlineTime", connInfo.CreateTime, "reason", closeReason)

    // 示例2：获取连接绑定的用户ID
    userIDVal, exists := websocket.GetGlobalConnManager().GetConnAttr(connID, "user_id")
    userID := ""
    if exists {
        userID, _ = userIDVal.(string)
        logger.Info("用户下线", "userID", userID, "connID", connID)

        // 示例3：通知该用户的好友
        notifyMsg := map[string]interface{}{
            "action":     "friend.offline",
            "request_id": uuid.NewString(),
            "data": map[string]interface{}{
                "user_id":    userID,
                "conn_id":    connID,
                "offline_at": connInfo.CreateTime.Format("2006-01-02 15:04:05"),
                "reason":     closeReason,
            },
        }
        msgBytes, _ := json.Marshal(notifyMsg)
        // 给好友群发通知
        websocket.GetGlobalConnManager().Multicast([]string{"好友connID"}, string(msgBytes))
    }
}
```

**在入口文件中注册连接事件处理器**：

在 `api.go` 入口文件的 `init()` 函数中注册：

```go
package main

import (
    "github.com/dfpopp/go-dai/bootstrap"
    "github.com/dfpopp/go-dai/websocket"
    "myproject/app/api/init/ws"
    "myproject/app/api/router"
)

// init函数：在main函数执行前自动执行，用于注册连接事件处理器
func init() {
    // 1. 获取全局连接管理器
    connManager := websocket.GetGlobalConnManager()
    
    // 2. 获取事件管理器
    eventMgr := connManager.GetEventManager()
    
    // 3. 注册自定义事件处理器
    customListener := ws.NewCustomConnListener()
    eventMgr.RegisterHandler(customListener)
}

func main() {
    appName := "api"
    
    // 构建启动配置（启用WS服务）
    bootCfg := &bootstrap.BootConfig{
        AppName:            appName,
        AppConfigPath:      "config/app.json",
        DatabaseConfigPath: "config/database.json",
        CustomConfigPath:   "config/custom.json",
        EnableServices:     []bootstrap.ServiceType{bootstrap.ServiceTypeWS}, // 启用WS服务
        Router:             router.NewApiRouter(),
    }
    
    // 一键启动服务
    _, err := bootstrap.Boot(bootCfg)
    if err != nil {
        panic("应用启动失败: " + err.Error())
    }
}
```

**注意事项**：

1. **必须在 `init()` 函数中注册**：连接事件处理器必须在 WebSocket 服务启动前注册，使用 `init()` 函数可以确保在 `main()` 函数执行前完成注册。

2. **事件处理器可以有多个**：可以注册多个事件处理器，框架会按注册顺序依次调用。

3. **连接属性绑定**：在业务逻辑中可以通过 `SetConnAttr()` 绑定用户ID等属性，在事件处理器中通过 `GetConnAttr()` 获取。

4. **下线原因**：`OnDisconnect` 的 `reason` 参数包含下线原因，如 "normal closure"、"client closed connection" 等。

#### gRPC 完整开发流程

##### 步骤1：定义 Protobuf 文件

Protobuf 文件定义了 gRPC 服务的接口规范，包括消息类型和服务方法。

**创建目录结构**：

```
your-project/
├── proto/                  # Protobuf 定义目录
│   └─ user.proto          # 用户服务定义
├── gen/                    # 生成的代码目录
│   └─ user/               # 用户服务生成代码
│       ├─ user.pb.go      # 消息类型代码
│       └─ user_grpc.pb.go # gRPC 服务代码
```

**创建 `proto/user.proto` 文件**：

```protobuf
syntax = "proto3";  // 使用 proto3 版本

package user;       // 包名

// 指定生成代码的输出路径和包名
// ./gen/user 表示输出目录
// user 表示 Go 包名
option go_package = "./gen/user;user";

// ========== 消息定义 ==========

// 用户请求消息
message UserRequest {
    int32 id = 1;  // 用户ID，字段编号为1
}

// 用户响应消息
message UserResponse {
    int32 code = 1;     // 响应码
    string msg = 2;     // 响应消息
    UserData data = 3;  // 用户数据
}

// 用户数据消息
message UserData {
    int32 id = 1;       // 用户ID
    string username = 2; // 用户名
    string email = 3;    // 邮箱
    int32 age = 4;       // 年龄
}

// 创建用户请求消息
message CreateUserRequest {
    string username = 1; // 用户名
    string email = 2;    // 邮箱
    int32 age = 3;       // 年龄
}

// 创建用户响应消息
message CreateUserResponse {
    int32 code = 1;      // 响应码
    string msg = 2;      // 响应消息
    int32 user_id = 3;   // 创建的用户ID
}

// 用户列表请求消息
message UserListRequest {
    int32 page = 1;      // 页码
    int32 page_size = 2; // 每页数量
}

// 用户列表响应消息
message UserListResponse {
    int32 code = 1;           // 响应码
    string msg = 2;           // 响应消息
    repeated UserData list = 3; // 用户列表（repeated 表示数组）
    int32 total = 4;          // 总数
}

// ========== 服务定义 ==========

// 用户服务定义
service UserService {
    // 获取单个用户
    rpc GetUser(UserRequest) returns (UserResponse);
    
    // 创建用户
    rpc CreateUser(CreateUserRequest) returns (CreateUserResponse);
    
    // 获取用户列表
    rpc GetUserList(UserListRequest) returns (UserListResponse);
}
```

**Protobuf 文件说明**：

| 语法 | 说明 |
|-----|------|
| `syntax = "proto3"` | 指定使用 proto3 版本 |
| `package user` | 定义包名，防止命名冲突 |
| `option go_package` | 指定 Go 代码输出路径和包名 |
| `message` | 定义消息类型（请求/响应） |
| `service` | 定义服务接口 |
| `rpc` | 定义服务方法 |
| `int32/string` | 字段类型 |
| `= 1/2/3` | 字段编号（唯一标识） |
| `repeated` | 表示数组类型 |

```go

type UserServiceServer interface {
    GetUser(context.Context, *UserRequest) (*UserResponse, error)
    CreateUser(context.Context, *CreateUserRequest) (*CreateUserResponse, error)
    GetUserList(context.Context, *UserListRequest) (*UserListResponse, error)
}

// UnimplementedUserServiceServer 未实现的服务（用于继承）
type UnimplementedUserServiceServer struct {}

// UserService_ServiceDesc 服务描述（用于注册）
var UserService_ServiceDesc = grpc.ServiceDesc{
    ServiceName: "user.UserService",
    HandlerType: (*UserServiceServer)(nil),
    Methods: []grpc.MethodDesc{
        {
            MethodName: "GetUser",
            Handler:    _UserService_GetUser_Handler,
        },
        // ...
    },
}
```

##### 步骤3：编写 gRPC 控制器

**gRPC 控制器与 HTTP/WebSocket 控制器的区别**：

| 特性 | HTTP/WebSocket 控制器 | gRPC 控制器 |
|-----|---------------------|------------|
| **继承** | `base.BaseController` | `base.BaseController` + `UnimplementedXXXServer` |
| **方法签名** | `func(ctx netContext.Context)` | `func(ctx context.Context, req *Request) (*Response, error)` |
| **参数获取** | `c.GetPostForm("id")` | 直接使用 `req.Id` |
| **响应返回** | `c.Success(data)` | 返回 `&Response{Code:0, Data:data}` |
| **错误处理** | `c.Error(400, "错误")` | 返回 `&Response{Code:400, Msg:"错误"}, nil` |
| **类型安全** | 弱类型（string/map） | 强类型（Protobuf定义） |

**创建 `app/api/controller/user/user.go`**：

```go
package user

import (
    "context"
    "strconv"
    
    "myproject/app/api/service/user"
    "myproject/gen/user"  // 导入生成的 gRPC 代码
    
    "github.com/dfpopp/go-dai/base"
)

// Controller gRPC 控制器
// 注意：必须同时继承 BaseController 和 UnimplementedUserServiceServer
type Controller struct {
    *base.BaseController                      // 框架基类
    user.UnimplementedUserServiceServer       // gRPC 未实现基类（必须继承）
    userService *user.Service                 // 服务层实例
}

// NewController 创建控制器实例
func NewController() *Controller {
    return &Controller{
        BaseController:                   &base.BaseController{},
        UnimplementedUserServiceServer:   user.UnimplementedUserServiceServer{},
        userService:                      user.NewService(),
    }
}

// GetUser 获取单个用户
// 注意：gRPC 方法签名与 HTTP/WebSocket 不同
// 参数：ctx context.Context（标准 Go context）
// 参数：req *user.UserRequest（强类型请求，直接访问字段）
// 返回：*user.UserResponse（强类型响应）
// 返回：error（gRPC 错误，一般返回 nil，错误信息放在响应中）
func (c *Controller) GetUser(ctx context.Context, req *user.UserRequest) (*user.UserResponse, error) {
    // 1. 参数获取（直接访问强类型字段，无需解析）
    userId := int(req.Id)
    
    // 2. 参数校验
    if userId <= 0 {
        // gRPC 错误处理：返回响应对象，而非调用 c.Error()
        return &user.UserResponse{
            Code: 400,
            Msg:  "用户ID非法",
            Data: nil,
        }, nil  // 注意：第二个返回值是 error，一般返回 nil
    }
    
    // 3. 调用服务层（与 HTTP/WebSocket 相同）
    userInfo, err := c.userService.GetUserById(userId)
    if err != nil {
        return &user.UserResponse{
            Code: 500,
            Msg:  err.Error(),
            Data: nil,
        }, nil
    }
    
    // 4. 响应封装（使用强类型结构）
    return &user.UserResponse{
        Code: 0,
        Msg:  "操作成功",
        Data: &user.UserData{
            Id:       int32(userInfo.ID),
            Username: userInfo.Username,
            Email:    userInfo.Email,
            Age:      int32(userInfo.Age),
        },
    }, nil
}

// CreateUser 创建用户
func (c *Controller) CreateUser(ctx context.Context, req *user.CreateUserRequest) (*user.CreateUserResponse, error) {
    // 1. 参数校验
    if req.Username == "" {
        return &user.CreateUserResponse{
            Code: 400,
            Msg:  "用户名不能为空",
        }, nil
    }
    if req.Email == "" {
        return &user.CreateUserResponse{
            Code: 400,
            Msg:  "邮箱不能为空",
        }, nil
    }
    
    // 2. 调用服务层
    data := map[string]interface{}{
        "username": req.Username,
        "email":    req.Email,
        "age":      int(req.Age),
    }
    
    userId, err := c.userService.CreateUser(data)
    if err != nil {
        return &user.CreateUserResponse{
            Code: 500,
            Msg:  err.Error(),
        }, nil
    }
    
    // 3. 响应封装
    return &user.CreateUserResponse{
        Code:   0,
        Msg:    "创建成功",
        UserId: int32(userId),
    }, nil
}

// GetUserList 获取用户列表
func (c *Controller) GetUserList(ctx context.Context, req *user.UserListRequest) (*user.UserListResponse, error) {
    // 1. 参数处理
    page := int(req.Page)
    pageSize := int(req.PageSize)
    
    if page <= 0 {
        page = 1
    }
    if pageSize <= 0 {
        pageSize = 10
    }
    
    // 2. 调用服务层
    userList, total, err := c.userService.GetUserList(page, pageSize)
    if err != nil {
        return &user.UserListResponse{
            Code: 500,
            Msg:  err.Error(),
        }, nil
    }
    
    // 3. 响应封装（repeated 字段需要转换为数组）
    list := make([]*user.UserData, 0)
    for _, userInfo := range userList {
        list = append(list, &user.UserData{
            Id:       int32(userInfo.ID),
            Username: userInfo.Username,
            Email:    userInfo.Email,
            Age:      int32(userInfo.Age),
        })
    }
    
    return &user.UserListResponse{
        Code:  0,
        Msg:   "操作成功",
        List:  list,
        Total: int32(total),
    }, nil
}
```

**gRPC 控制器编写要点**：

1. **必须继承两个基类**：
   - `base.BaseController`：框架基类
   - `user.UnimplementedUserServiceServer`：gRPC 未实现基类

2. **方法签名固定**：
   - `func(ctx context.Context, req *Request) (*Response, error)`
   - 使用标准 Go context，而非框架 netContext

3. **参数获取方式**：
   - 直接访问强类型字段：`req.Id`、`req.Username`
   - 无需手动解析，类型安全

4. **响应返回方式**：
   - 返回强类型响应对象：`&user.UserResponse{Code:0, Msg:"成功"}`
   - 第二个返回值是 error，一般返回 nil

5. **错误处理方式**：
   - 错误信息放在响应对象的 Msg 字段
   - 使用 Code 字段标识错误类型（400/500等）

#### gRPC 开发注意事项

1. **Protobuf 文件管理**：
   - proto 文件应放在 `proto/` 目录
   - 生成的代码应放在 `gen/` 目录
   - proto 文件修改后需重新生成代码

2. **控制器继承**：
   - 必须继承 `base.BaseController`
   - 必须继承 `UnimplementedXXXServer`
   - 必须实现所有定义的 rpc 方法

3. **方法签名**：
   - 使用标准 Go context，而非框架 netContext
   - 参数和返回值必须是强类型 Protobuf 消息
   - 第二个返回值是 error，一般返回 nil

4. **错误处理**：
   - 错误信息放在响应对象的 Msg 字段
   - 使用 Code 字段标识错误类型
   - 不应直接返回 Go error（除非是系统级错误）

5. **服务注册**：
   - 使用生成的 `RegisterXXXServiceServer` 函数
   - 传入 `grpcServer.GrpcServer`（原生 gRPC Server）
   - 传入控制器实例

6. **SSL/TLS 加密**：
   - 生产环境建议启用 SSL
   - 需配置证书和密钥文件路径
   - 客户端需要使用对应的证书

## 开发指南

### 三种协议路由对比

go-Dai 框架支持三种协议：HTTP、WebSocket、gRPC，它们的路由注册方式有所不同。

#### HTTP 路由

**特点**：
- 使用 RESTful 风格的 URL 路径
- 支持 GET、POST、PUT、DELETE 等 HTTP 方法
- 通过 URL 路径和 HTTP 方法组合标识路由

**路由注册方式**：

```go
func (r *ApiRouter) RegisterHTTPRoutes(server *http.Server) {
    // 使用 HTTP 方法和 URL 路径注册路由
    server.POST("/user/info", http.ToHTTPHandler(r.userController.GetUser), middleware.Auth())
    server.GET("/user/list", http.ToHTTPHandler(r.userController.GetList), middleware.Auth())
    server.PUT("/user/update", http.ToHTTPHandler(r.userController.Update), middleware.Auth())
    server.DELETE("/user/delete", http.ToHTTPHandler(r.userController.Delete), middleware.Auth())
}
```

**客户端请求格式**：

```http
POST /user/info HTTP/1.1
Content-Type: application/json

{
  "id": "123"
}
```

#### WebSocket 路由

**特点**：
- 使用 action 标识路由（如 `user.get`）
- 客户端发送 JSON 格式消息，包含 action、request_id、data
- 支持双向通信，服务器可主动推送消息
- 需要连接事件监听（用户上线、下线）

**路由注册方式**：

```go
func (r *ApiRouter) RegisterWSRoutes(wsServer *websocket.Server) {
    // 使用 action 注册路由
    wsServer.Register("user.get", websocket.ToWSHandler(r.userController.GetUser), middleware.WsAuth())
    wsServer.Register("user.login", websocket.ToWSHandler(r.userController.Login))
    wsServer.Register("message.send", websocket.ToWSHandler(r.messageController.Send))
}
```

**客户端请求格式**：

```json
{
  "action": "user.get",
  "request_id": "uuid-1234",
  "data": {
    "id": "123"
  }
}
```

**连接事件监听注册方式**：

```go
// 在入口文件的 init() 函数中注册
func init() {
    connManager := websocket.GetGlobalConnManager()
    eventMgr := connManager.GetEventManager()
    customListener := ws.NewCustomConnListener()
    eventMgr.RegisterHandler(customListener)
}
```

#### gRPC 路由

**特点**：
- 使用 Protobuf 定义服务和方法
- 通过服务名和方法名标识路由
- 支持强类型定义和代码生成
- 需要定义 .proto 文件并生成代码
- 控制器必须继承 `UnimplementedXXXServer`

**路由注册方式**：

```go
func (r *ApiRouter) RegisterGRPCRoutes(grpcServer *grpc.Server) {
    // 注册 gRPC 服务
    // 使用生成的 RegisterUserServiceServer 函数
    // 传入 grpcServer.GrpcServer（原生 gRPC Server）
    // 传入控制器实例
    user.RegisterUserServiceServer(grpcServer.GrpcServer, r.grpcUserController)
}
```

**Protobuf 定义格式**：

```protobuf
syntax = "proto3";

package user;
option go_package = "./gen/user;user";

service UserService {
    rpc GetUser(UserRequest) returns (UserResponse);
    rpc CreateUser(CreateUserRequest) returns (CreateUserResponse);
}
```

**控制器方法签名**：

```go
// gRPC 控制器方法签名（与 HTTP/WebSocket 不同）
func (c *Controller) GetUser(ctx context.Context, req *user.UserRequest) (*user.UserResponse, error) {
    // 参数：强类型请求对象，直接访问字段 req.Id
    // 返回：强类型响应对象
    // 返回：error（一般返回 nil，错误信息放在响应中）
}
```

**客户端调用方式**：

```go
// gRPC 客户端调用
client := user.NewUserServiceClient(conn)
resp, err := client.GetUser(ctx, &user.UserRequest{Id: 123})
```

#### 三种协议对比表

| 特性 | HTTP | WebSocket | gRPC |
|-----|------|-----------|------|
| **路由标识** | URL路径 + HTTP方法 | action | 服务名 + 方法名 |
| **通信方式** | 单向请求响应 | 双向通信 | 单向请求响应 |
| **消息格式** | JSON/Form | JSON | Protobuf |
| **连接状态** | 无状态 | 有状态（长连接） | 有状态（长连接） |
| **事件监听** | 无 | 有（上线/下线） | 无 |
| **适用场景** | RESTful API | 实时通信、推送 | 微服务、高性能RPC |
| **注册方法** | `server.POST/GET/PUT/DELETE` | `wsServer.Register` | `server.RegisterService` |
| **入口文件注册** | `RegisterHTTPRoutes` | `RegisterWSRoutes` + `init()` | `RegisterGRPCRoutes` |

### 如何创建控制器

控制器负责请求分发、参数校验、响应封装，不直接操作数据。

**创建步骤**：

1. 继承 `base.BaseController`
2. 注入服务层实例
3. 实现 `NewController()` 初始化方法
4. 实现具体的控制器方法

**示例**：

```go
package user

import (
    "myproject/app/api/service/user"
    "github.com/dfpopp/go-dai/base"
    "github.com/dfpopp/go-dai/netContext"
)

type Controller struct {
    *base.BaseController
    userService *user.Service
}

func NewController() *Controller {
    return &Controller{
        BaseController: &base.BaseController{},
        userService:    user.NewService(),
    }
}

func (c *Controller) GetUser(ctx netContext.Context) {
    c.Init(ctx) // 必须调用Init方法
    
    // 参数获取
    userIdStr := c.GetPostForm("id")
    
    // 参数校验
    if userIdStr == "" {
        c.Error(400, "用户ID不能为空")
        return
    }
    
    // 调用服务层
    userId, _ := strconv.Atoi(userIdStr)
    userInfo, err := c.userService.GetUserById(userId)
    if err != nil {
        c.Error(500, err.Error())
        return
    }
    
    // 统一响应
    c.Success(userInfo)
}
```

### 如何创建路由

### 如何创建中间件

中间件是请求处理的拦截器，可以用于认证、限流、日志记录等。

**创建步骤**：

1. 定义中间件函数
2. 实现中间件逻辑
3. 调用 `next(c)` 执行后续处理

**示例**：

```go
package middleware

import (
    "time"
    "github.com/dfpopp/go-dai/http"
)

// 认证中间件
func Auth() http.MiddlewareFunc {
    return func(next http.HandlerFunc) http.HandlerFunc {
        return func(c *http.Context) {
            token := c.GetHeader("Authorization")
            if token == "" {
                c.JSON(200, map[string]interface{}{
                    "code": 401,
                    "msg":  "未授权访问",
                })
                return
            }
            
            // Token验证逻辑
            if !validateToken(token) {
                c.JSON(200, map[string]interface{}{
                    "code": 401,
                    "msg":  "Token无效",
                })
                return
            }
            
            next(c)
        }
    }
}

// 日志中间件
func Logger() http.MiddlewareFunc {
    return func(next http.HandlerFunc) http.HandlerFunc {
        return func(c *http.Context) {
            startTime := time.Now()
            
            // 执行后续处理
            next(c)
            
            endTime := time.Now()
            duration := endTime.Sub(startTime)
            
            // 记录日志
            fmt.Printf("[%s] %s %s %v\n",
                startTime.Format("2006-01-02 15:04:05"),
                c.Req.Method,
                c.Req.URL.Path,
                duration,
            )
        }
    }
}

// 限流中间件
func RateLimit(maxRequests int) http.MiddlewareFunc {
    requestCount := 0
    return func(next http.HandlerFunc) http.HandlerFunc {
        return func(c *http.Context) {
            requestCount++
            if requestCount > maxRequests {
                c.JSON(200, map[string]interface{}{
                    "code": 429,
                    "msg":  "请求过于频繁",
                })
                return
            }
            next(c)
        }
    }
}
```

## 最佳实践

### 分层设计原则

1. **控制器层**：
   - 仅负责请求分发、参数校验、响应封装
   - 不直接操作数据库
   - 仅调用服务层

2. **服务层**：
   - 封装核心业务逻辑
   - 仅通过模型层操作数据
   - 不依赖协议相关的上下文

3. **模型层**：
   - 映射数据实体
   - 负责 CRUD 操作
   - 仅被服务层调用

### 多协议复用原则

服务层和模型层应完全脱离协议依赖，仅控制器层需要适配不同协议：

```go
// 服务层（多协议复用）
func (s *Service) GetUserById(userId int) (*User, error) {
    // 无协议依赖
    return s.userModel.GetOne("id=?", []interface{}{userId})
}

// HTTP控制器（适配HTTP协议）
func (c *Controller) GetUser(ctx netContext.Context) {
    c.Init(ctx)
    userId, _ := strconv.Atoi(c.GetPostForm("id"))
    userInfo, err := c.userService.GetUserById(userId)
    c.Success(userInfo)
}

// WebSocket控制器（适配WebSocket协议）
func (c *WsController) GetUser(ctx netContext.Context) {
    c.Init(ctx)
    type Req struct {
        ID string `json:"id"`
    }
    var req Req
    ctx.BindJSON(&req)
    userId, _ := strconv.Atoi(req.ID)
    userInfo, err := c.userService.GetUserById(userId)
    c.Success(userInfo)
}

// gRPC控制器（适配gRPC协议）
func (c *GrpcController) GetUser(ctx context.Context, req *pb.UserRequest) (*pb.UserResponse, error) {
    userId := int(req.Id)
    userInfo, err := c.userService.GetUserById(userId)
    return &pb.UserResponse{
        Code: 0,
        Msg:  "操作成功",
        Data: userInfo,
    }, nil
}
```

### 错误处理原则

1. **统一错误响应**：使用 `c.Error(code, msg)` 统一响应错误
2. **错误日志记录**：在服务层和模型层使用 `s.LogError(err)` 记录错误日志
3. **错误传递**：错误应从底层向上层传递，并在控制器层统一处理

### 性能优化建议

1. **数据库连接池**：合理配置连接池参数
2. **查询优化**：避免全表查询，使用索引
3. **缓存使用**：合理使用 Redis 缓存
4. **并发控制**：使用中间件进行限流

## 常见问题

### Q1：如何同时启动多个服务？

使用 `EnableServices` 配置多个服务类型：

```go
bootCfg := &bootstrap.BootConfig{
    EnableServices: []bootstrap.ServiceType{
        bootstrap.ServiceTypeHTTP,
        bootstrap.ServiceTypeWS,
        bootstrap.ServiceTypeGRPC,
    },
}
```

### Q2：如何实现 WebSocket 用户绑定？

在 WebSocket 控制器中使用 `BindUserID` 方法：

```go
func (c *WsController) Login(ctx netContext.Context) {
    c.Init(ctx)
    userId := c.GetPostForm("userId")
    err := c.BindUserID(userId)
    if err != nil {
        c.Error(400, err.Error())
        return
    }
    c.Success(nil, "登录成功")
}
```

### Q3：如何实现 WebSocket 消息推送？

使用 BaseController 提供的消息推送方法：

```go
// 发送给指定连接
err := c.SendToConnID(connID, "message.action", data)

// 发送给指定用户（自动获取用户所有连接）
err := c.SendToUser(userId, "message.action", data)

// 发送给多个用户
err := c.SendToUsers(userIds, "message.action", data)
```

### Q4：如何配置数据库连接池？

在 `config/database.json` 中配置：

```json
{
  "mysql": {
    "default": {
      "max_open_conn_num": 100,
      "max_idle_conn_num": 10,
      "conn_max_idleTime": 300,
      "conn_max_lifetime": 1800
    }
  }
}
```

### Q5：如何实现优雅停机？

框架已内置优雅停机机制，无需额外配置。服务关闭时会：
1. 执行业务层清理逻辑（ShutdownFunc）
2. 关闭数据库连接
3. 停止 HTTP/WebSocket/gRPC 服务

### Q6：如何添加自定义配置？

1. 创建 `config/custom.json` 文件
2. 在启动配置中指定 `CustomConfigPath`
3. 使用 `config.GetCustomConfig()` 获取配置

```go
bootCfg := &bootstrap.BootConfig{
    CustomConfigPath: "config/custom.json",
}

customConfig := config.GetCustomConfig()
value := customConfig.GetConfig().Get("custom_key").String()
```
